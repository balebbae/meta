## Why another name may appear in the commit history

Some commits made on **Nov 12, 2026** were originally recorded with the git identity **`mstxus-dgx`**. That is not a
team member. It is the default git identity of the **NVIDIA DGX Spark** that belongs to Veer's dad, which he lent us so
we could fine-tune Muse Glimmer for the Rally proof check (see `finetune/`). Git stamps commits with the machine's
configured identity, not with the GitHub account that pushes them, so work Veer did on that machine showed up under it.
Veer's dad did not write code or contribute to the project; we only used his hardware.

We corrected the authorship of those commits on `main` to Veer Shah on Nov 13, 2026. GitHub may still show the old
identity for a while in cached views (the contributors graph) and in the commit lists of already-merged pull requests
#26 and #27, which keep a snapshot of the original commits.
